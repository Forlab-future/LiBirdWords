# LiBird Words

일본어(히라가나부터) · 영어(학술 어휘·숙어·논문 문장·SOFC 전공어휘) 학습 웹앱.
접속: https://forlab-future.github.io/LiBirdWords/

## 기능

- **언어 전환**: 상단 「あ 일본어 | Aa 영어」로 앱 전체가 그 언어 전용으로 바뀜 (색도 주황/파랑)
- **학습**: 간격 반복(SRS) · 답하는 법(타이핑 / 객관식 / 스스로) · 방향(단어→뜻 / 뜻→단어 / 섞기)
  - 타이핑 채점: 여러 뜻·비슷한 말·오타 허용, "내 답도 맞아요"로 인정한 답 저장, AI 채점(선택)
  - 문장 카드는 해석 또는 빈칸 채우기로 공부
  - 자유 복습(일정에 영향 없음), 단어장 골라 공부, 아는 단어 거르기
- **단어장**: 검색·상태 필터, 카드 상세·수정, **내 단어장**(직접 입력 / 붙여넣기 / AI로 채우기)
- **읽기**: 한 문단 글 — 문장별 듣기, 해석, 핵심 단어, 이해 문제, 단어 눌러 단어장 추가, AI로 글 만들기, 직접 붙여넣기
- **게임**: 짝 맞추기, 60초 스피드 퀴즈, 듣고 고르기, 빈칸 채우기, (일본어) 가나 퀴즈·헷갈리는 글자·가나표
- **통계**: 학습 달력, 앞으로 7일 복습 예정, 카드 상태, 자주 틀리는 카드
- **AI에게 묻기**: 단어 뜻·쓰임새·뉘앙스 질문 (Claude API 키 필요, 브라우저에서 직접 호출)
- **동기화**: 학습 기록을 동기화 비밀번호로 암호화(AES-GCM)해 `progress` 브랜치에 기기별 파일로 저장, 다른 기기는 QR로 연결
